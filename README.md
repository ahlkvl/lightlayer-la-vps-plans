## 三条线路怎么选：CMIN2、标准、国际

**Premium 优化线路**是这批里唯一针对中国大陆做过优化的，洛杉矶机房走三网 CMIN2 直连，电信、联通、移动的回程都在这条线上。国内访问优先选它，没有别的理由选更贵的方案。

**Standard 标准线路**按较早的活动页说明是移动 CMI 直连，定位在“价格和带宽之间取平衡”。它的带宽比 Premium 高一档（50Mbps 对 20Mbps，或 100Mbps 对 30Mbps），但国内三网的覆盖不如 CMIN2 全面。如果你的用户以移动网络为主，或者对国内访问速度只有“能打开”这种要求，Standard 的性价比更高。

**Global 国际线路**走国际带宽，不针对中国大陆做优化，带宽给到 100Mbps 不限流量或 200Mbps / 1TB。它的服务对象是外贸站、面向海外用户的 API、海外分发节点这类场景。**如果你的访客主要在国内，选 Global 是这批套餐里最容易出错的一步**，带宽数字越大，晚高峰绕路带来的落差越明显。

电信用户还有个额外判断：CMIN2 对电信有优化，但和 CN2 GIA 不是一回事。晚高峰对电信回程要求极高的话，$24.99 这一档未必够用，得往 CN2 GIA 产品线去找，价格会明显上一个台阶，后面竞品对比里会给出参照。

结论在表里：**1TB 档的带宽足够高，跑到满速十几个小时就用完了；不限流量档的带宽低，但理论上限远高于 1TB。** 你选的是“短时间跑得快”还是“长时间跑得稳”。

个人博客、企业展示站、代理节点、爬虫、轻量 API，一天跑不了几十 GB，1TB 的配额基本用不完，那就选带宽高的那一款。做备份同步、视频转存、持续下载这类会长期占用带宽的业务，20Mbps 不限流量反而更合适，至少不用担心月底被掐。

另外 1TB 到底是月流量还是年总量，公开资料没有写清楚。**下单前在套餐页确认这一条**，如果是年总量，1TB 摊到每个月只有 80 多 GB，选择就要反过来。
